Selected work

Capstone design / 2026–present

Haptic Smart
Control Knob

I’m developing a motorized dial that can change how it feels as you turn it. Magnetic angle feedback lets the controller apply motor torque to create programmable detents, resistance, and virtual end stops.

  • ESP32
  • BLDC
  • MT6701
  • TMC6300
  • KiCad
Engineering notes

The MT6701 measures shaft angle. The ESP32 uses that feedback to command a TMC6300 driver and three-phase gimbal motor. I’m defining how host software will select feedback profiles over USB and preparing schematics for custom PCB integration.

Purdue IEEE Racing / 2025–26

Electric Vehicle
Localization

I implemented visual-inertial SLAM to estimate an electric vehicle’s position in real time. I also designed and tested power distribution and safety circuits and integrated ESP32 controllers for embedded sensing.

  • Visual-inertial SLAM
  • ESP32
  • C/C++
  • Python
Engineering notes

Visual-inertial SLAM combines camera observations with inertial measurements to estimate motion. I worked on the hardware and software interfaces that supported navigation and vehicle-control development, alongside the electrical, mechanical, and software teams.
